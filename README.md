# موقع مراجعة الفلسفة

نموذج أولي لموقع ثابت موجه لطالبة ثانية باك علوم فيزيائية بالمغرب.

## طريقة الفتح

افتحي الملف `index.html` مباشرة في المتصفح. لا يحتاج الموقع إلى خادم أو Backend أو مكتبات خارجية.

## الملفات

- `index.html`: بنية الصفحة الرئيسية وأقسام المجزوءة والدرس.
- `styles.css`: التصميم المتجاوب، RTL، وMobile First.
- `data.js`: المحتوى التجريبي الخاص بمجزوءة الوضع البشري ودرس الشخص.
- `app.js`: التفاعل، البحث، إظهار التصحيح، حفظ التقدم في `localStorage`.
- `README.md`: شرح مختصر لطريقة استعمال وتعديل الموقع.

## تعديل المحتوى

لتعديل الدروس أو إضافة دروس جديدة، افتح ملف `data.js` وعدل البيانات داخل `PHILOSOPHY_DATA`.

يمكن إضافة درس جديد داخل `lessons` بنفس البنية:

```js
{
  id: "lesson-id",
  title: "عنوان الدرس",
  summary: "ملخص قصير",
  mindMap: ["فكرة أولى", "فكرة ثانية"],
  questions: [
    {
      text: "نص السؤال",
      answer: true,
      correction: "التصحيح"
    }
  ],
  writingPrompt: "تدريب كتابي",
  modelAnswer: "نموذج جواب مختصر"
}
```

## ملاحظات

- ملفات Word الأصلية خارج هذا المجلد لم يتم تعديلها.
- التقدم يحفظ محليا في متصفح الطالبة عبر `localStorage`.
- عند فتح الموقع في متصفح آخر أو جهاز آخر سيبدأ التقدم من جديد.
